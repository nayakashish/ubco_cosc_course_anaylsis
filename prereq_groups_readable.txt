PREREQUISITE GROUPS - READABLE VERSION (for checking prereq_groups.csv)

How to read it:
  AND            both sides are required
  OR             any one of the options is enough
  [ ... ]  ||  [ ... ]   two alternative routes; either route unlocks the course
  STANDING_3 / STANDING_4   third / fourth-year standing (treated as always satisfied)
  HS_ENTRY       high-school entry courses (treated as always satisfied)
Each course shows the formula we encoded, then the original calendar text so you can compare.
Corequisites are not included. Please check each formula against the calendar line under it.
